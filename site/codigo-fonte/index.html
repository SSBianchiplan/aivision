Código-fonte do GPlanSiS|iaVision

Este protótipo usa modelos Ultralytics YOLO26 e YOLOE, distribuídos sob a licença GNU AGPL-3.0. Por isso o código-fonte completo do sistema está disponível aqui, sob a mesma licença, para quem o usa pela rede.

  • aivision-fonte.tar.gz: HTML, JavaScript (operadores, runtime ONNX, interface), estilos e service worker, o módulo Treinar modelos (/treino/) e o serviço de treino (pasta servico-treino: API FastAPI, job de treino Ultralytics, Dockerfile e compose), sem os pesos dos modelos.
  • Texto da licença GNU AGPL-3.0.
  • Pesos dos modelos: servidos pelo próprio site em /models/ e /relacoes/models/ (o app os baixa ao habilitar cada módulo). Os YOLO26/YOLOE são da Ultralytics (AGPL-3.0); os demais mantêm as licenças das origens indicadas no painel de cada módulo.
